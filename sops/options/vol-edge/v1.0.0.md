# Options Vol-Edge Strategy — v1.0.0

## Overview

This is a **swing strategy SOP** (multi-day holds, 30–120 DTE options). It **explicitly overrides
the day-trade 15:45 flatten**: `OPERATING_MANUAL.md` Rule 7 states the 15:45 time stop is
"non-negotiable *for day-trade SOPs*" — this is not a day-trade SOP, so positions may be held
overnight and across sessions. The daily loop runs an exit check at **15:30 ET** instead; no
mechanical end-of-day close is applied to open options positions.

`OPERATING_MANUAL.md` is the constitution and wins on every conflict. This SOP defers all
mode/limit/sizing-framework decisions to it and **only ever makes itself stricter, never looser**.

---

## Edge Thesis — Two Engines

The options book runs two complementary engines under one SOP, both gated by the same
equity-regime filter and both governed by `OPERATING_MANUAL.md`:

| | **Engine A — Vol-Edge (income)** | **Engine B — Directional / Big-Fish** |
|---|---|---|
| Edge | Vol mispricing: sell rich (IVR > 75), buy cheap (IVR < 25) | Trend continuation — catch the runner |
| Structures | Bull put / bear call credit spreads + debit verticals | Momentum debit spreads + leashed single-leg longs |
| Profit shape | Capped, high win-rate | Spread: capped 3–8× · single-leg: uncapped |
| Scored on | IVR / IV-HV / put-skew | RS63 + regime strength + setup quality |
| Risk | Defined (spread width or premium) | Defined (spread width or premium) |

Both engines are **defined-risk only** — no naked options. Single-leg longs are the sole uncapped
instrument; they are deliberately leashed (see Sizing).

Tiers read **live equity** at the start of each session — compounding is structural, not manual.
The system moves between tiers automatically as equity crosses the thresholds below.

| Tier | Equity | Options? | Spread width | Notes |

gate and fallback hook are noted; the bridge SOP itself is a separate future specification.

## Phase 1: Scan

### Market Context

**SPY Regime (EMA20 / SMA50 / SMA200)**

Compute each morning before the first scan pass. Three possible classifications:

| Classification | Condition |
|---|---|
| **UPTREND** | `Close > EMA20 > SMA50 > SMA200` AND SMA50 slope > 0 over last 10 bars |
| **DOWNTREND** | `Close < EMA20 < SMA50 < SMA200` AND SMA50 slope < 0 over last 10 bars |
| **NEUTRAL** | All other cases |

**VIX Bands**

| VIX Level | Market Condition | Action |
|---|---|---|
| `< 15` | Compressed vol | Favor single-name elevated IVR opportunities |
| `15–25` | Normal | No adjustment |
| `> 25` | Elevated | Reduce spread widths |
| `> 35` | Spike / stress | No new debit long positions |

**Macro Calendar**

- **Hold new entries** the morning of FOMC / CPI / PPI / NFP until 30 minutes after the release.
- If a market-moving scheduled event (FOMC, CPI, PPI, NFP) lands **inside** the intended expiry window, either widen the spread to absorb expected vol expansion, or wait for the event to pass before entering.

---

### IV & Regime Filter

**Formulas (compute these for every candidate):**

```
IVR      = (IV30 − IV30_52wk_low) / (IV30_52wk_high − IV30_52wk_low) × 100
IV/HV    = IV30 / HV20
RS63     = stock_63d_return − SPY_63d_return
put_skew = IV_OTM_put − IV_equidistant_OTM_call
```

**Engine A Vol Routing (IVR threshold)**

| IVR | Signal | Engine A action |
|---|---|---|
| `> 75` | Rich vol | Sell premium → credit spread |
| `< 25` | Cheap vol | Buy premium → debit spread |
| `25–75` | No vol edge | Engine A **skips**; Engine B may still qualify on momentum |

**Equity Regime Gate**

The option structure must agree with the SPY regime:

- **UPTREND** → RS63 must be > 0; bullish structures only (bull put spread, long call debit spread, long call).
- **DOWNTREND** → RS63 must be < 0; bearish structures only (bear call spread, long put debit spread, long put).
- **NEUTRAL** → Engine A skips (no directional credit). Engine B waits for a confirmed directional regime.

**Put Skew Signal**

`put_skew > 5` specifically favors selling puts (bull put spread) over the symmetric bearish equivalent, independent of the regime-direction gate above.

---

### Liquidity & Earnings Gates

All four sub-checks below are **hard gates** — fail any one and skip the candidate.

**Liquidity**

| Check | Minimum | Preferred |
|---|---|---|
| 20-day average dollar volume | ≥ $20M | — |
| Option open interest (target strike) | ≥ 100 | ≥ 500 |
| Bid-ask spread on the spread | ≤ 20% of mid | tighter |

**Earnings**

- The **confirmed** earnings date must fall **entirely outside** the expiry window, OR the expiry window must **start > 7 calendar days after earnings**.
- **If the earnings date is unavailable or uncertain → skip the candidate. Do not guess.**

## Phase 2: Structure, Strike & Expiry Selection

### Engine A — Vol-Edge Structures

Route by the vol signal and SPY regime determined in Phase 1:

| Vol signal | Regime | Structure |
|---|---|---|
| Rich vol (IVR > 75) | UPTREND | **Bull put spread** — sell OTM put, buy lower put |
| Rich vol (IVR > 75) | DOWNTREND | **Bear call spread** — sell OTM call, buy higher call |
| Cheap vol (IVR < 25) | UPTREND or DOWNTREND | **Debit vertical** — buy ATM long leg, sell OTM short leg |

**Credit spread — short-strike delta target**

- Standard entry: **0.20–0.25 delta** on the short strike.
- When IVR > 90: move further OTM to **0.15 delta** (inflated vol gives credit at a safer strike).

**Debit vertical — long-leg and short-leg placement**

- Long leg: ATM, targeting **0.45–0.55 delta**.
- Short leg: approximately **1 expected-move OTM**, where:

```
expected_move = stock_price × IV × √(DTE / 365)
```

**Spread width by tier**

| Tier | Width |
|---|---|
| Small | $1–$2.50 |
| Standard | $5 |
| Pro | $5+ |

---

### Engine B — Directional / Big-Fish Structures

**Momentum debit spread**

Buy ATM, sell a **wider OTM short leg** targeting ~1.5–2 expected-moves out (preserves more
upside than the Engine A debit vertical). DTE: **60–90 days**.

**Single-leg long (call or put)**

DTE: **60–120 days** (blunt theta decay, give the move room to develop).

**IV-aware routing:** Engine B performs this check before committing to a single-leg long:

- If `IVR ≥ 50` (vol hot): **prefer the momentum debit spread** — the short leg sells back
  inflated premium and partially funds the long.
- `IVR < 50`: single-leg long is permitted.

**Engine B entry — continuation setup required**

Engine B REQUIRES one of the following confirmed continuation setups before entry. A move that
has already extended without you does not qualify — per `OPERATING_MANUAL.md` Rule 5:
*"a move that started without you is not your move."* Do not chase extended moves.

Accepted continuation setups (one must be present):

1. **Pullback-to-EMA20 with bullish reversal candle** — price pulled back to the 20-day EMA,
   the most recent bar shows a bullish reversal candle (hammer, engulfing, or pin bar), AND
   session volume on the reversal bar ≥ 1.2× the 20-day average daily volume.

2. **Consolidation breakout with Bollinger Band squeeze** — price has been consolidating in a
   tight range with Bollinger Bands contracted (squeeze condition), then breaks out of the range
   with session volume ≥ 1.5× the 20-day average daily volume.

3. **MACD resumption cross** — MACD line crosses above (bullish) or below (bearish) the signal
   line after a pullback, with the histogram turning in the direction of the trend — confirming
   momentum resumption, not a fresh-start reversal.

If none of these setups is present: **skip the candidate.**

---

### Expiry Rules

These windows apply at **entry** — never open a position that already violates them.

| Structure | DTE window | Hard floor |
|---|---|---|
| Credit spreads (bull put, bear call) | **30–45 DTE** | Never < 21 DTE at entry |
| Debit verticals (Engine A) | **60–90 DTE** | — |
| Momentum debit spreads (Engine B) | **60–90 DTE** | — |
| Single-leg longs (Engine B) | **60–120 DTE** | — |

**Earnings-vs-expiry rule (restatement from Phase 1 — enforced here at structure selection):**

The chosen expiry window must satisfy one of:

- Expiry falls **entirely before** the confirmed earnings date, OR
- The expiry window **starts > 7 calendar days after** earnings.

If neither condition is met with the available expiry dates: **skip the candidate or wait for
the event to pass.** If the earnings date is unavailable or uncertain: **skip. Do not guess.**

## Phase 3: Scoring

**Scope:** Scoring is applied ONLY to candidates that have passed ALL Phase 1 scan gates. Any
component marked "reject" in the rubrics below fails the candidate outright — the score is void
and the candidate is skipped. Do not average around a reject.

### Score scale and grade definitions

Both rubrics map to the same 0–100 scale so that `OPERATING_MANUAL.md`'s mode gates and
conviction-scaled sizing work identically across both engines:

| Grade | Score | Meaning |
|---|---|---|
| **A+** | 90–100 | Highest conviction. Full conviction sizing (see Sizing). |
| **A** | 80–89 | Strong. Standard conviction sizing. |
| **B+** | 70–79 | Permitted in NORMAL mode. Reduced conviction sizing. |
| **Reject** | < 70 | Do not trade. Candidate is discarded. |

**Mapping to the Manual's "A+" gate:** `OPERATING_MANUAL.md` §1 sets the DEFENSIVE-mode gate at
"A+ setups only (score ≥ 80)". This SOP uses a finer three-grade split above the reject line, so the
Manual's gate maps to **score ≥ 80 (grade A or A+)** — i.e. in DEFENSIVE mode, only grade A and A+
candidates may be entered. Grade B+ (70–79) is NORMAL-mode only.

**The score drives three downstream decisions:**
1. **DEFENSIVE mode gate** — Manual §1 blocks new entries unless score ≥ 80 (grade A or A+).
2. **Conviction-scaled sizing** — per-trade risk% is keyed to grade (see Sizing section).
3. **Research candidate ranking** — higher score = higher priority when multiple candidates compete for the same heat headroom.

---

### Rubric 1 — Vol-Edge Score (Engine A), 0–100

Score Engine A candidates (credit spreads and debit verticals) using this rubric. The nominal
maximum is 105 points; **the reported score is capped at 100**.

| Component | Points |
|---|---|
| **IVR magnitude** | **Credit structures (IVR ≥ 75):** IVR ≥ 90 → 30 pts · IVR 80–90 → 22 pts · IVR 75–80 → 15 pts · IVR < 75 → **reject** |
| | **Debit structures (IVR < 25):** IVR ≤ 15 → 30 pts · IVR 15–25 → 20 pts · IVR > 25 → **reject** |
| **IV/HV confirm** | **Credit:** IV/HV > 1.3 → 15 pts · IV/HV 1.1–1.3 → 8 pts · else → 0 pts |
| | **Debit:** IV/HV < 0.7 → 15 pts · IV/HV 0.7–0.85 → 8 pts · else → 0 pts |
| **Regime strength** | Full alignment + positive SMA50 slope → 20 pts · Partial alignment → 10 pts · Misaligned → **reject** |
| **RS63 rank** | Top 5% of universe → 15 pts · Top 10% → 10 pts · Top 20% → 5 pts · Positive (above zero) → 2 pts |
| **Liquidity/spread** | OI > 1000 AND bid-ask spread < 5% of mid → 10 pts · OI > 500 AND spread < 10% → 6 pts · OI > 100 → 3 pts · else → **reject** |
| **Earnings buffer** | Earnings > 14 calendar days outside the expiry window → 10 pts · Earnings 7–14 days outside → 5 pts · Earnings inside the expiry window → **reject** |
| **Put-skew bonus** | Bull put spread with put_skew > 5 → 5 pts · else → 0 pts |

**Nominal max: 30 + 15 + 20 + 15 + 10 + 10 + 5 = 105 points. The reported score is capped at
100.** A score of 100 means "maxed all components plus the bonus"; the cap prevents the bonus
from inflating the grade scale.

**Grades (per the scale above):** A+ 90–100 · A 80–89 · B+ 70–79 · reject < 70. **Manual DEFENSIVE gate:** score ≥ 80 (grade A or A+).

---

### Rubric 2 — Momentum Score (Engine B), 0–100

Score Engine B candidates (momentum debit spreads and single-leg longs) using this rubric.
Maximum is exactly 100 points; no cap needed.

| Component | Points |
|---|---|
| **RS63 rank** | Top 3% of universe → 30 pts · Top 5% → 24 pts · Top 10% → 15 pts · Top 20% → 8 pts · Outside top 20% → **reject** |
| **Regime strength** | Full alignment + positive SMA50 slope → 25 pts · Partial alignment → 12 pts · Misaligned → **reject** |
| **Continuation setup quality** | Textbook setup (all criteria cleanly met — see Phase 2 for accepted setups) → 25 pts · Decent setup (setup present but marginal) → 15 pts · No qualifying setup → **reject** |
| **Liquidity** | OI > 1000 AND bid-ask spread < 10% of mid → 10 pts · OI > 500 → 6 pts · OI > 100 → 3 pts · else → **reject** |
| **IV sanity (single-leg)** | IVR < 50 → 10 pts · IVR 50–70 → 5 pts · IVR > 70 → 0 pts (route to debit spread instead) |

**Maximum: 30 + 25 + 25 + 10 + 10 = 100 points.**

**Grades (per the scale above):** A+ 90–100 · A 80–89 · B+ 70–79 · reject < 70. **Manual DEFENSIVE gate:** score ≥ 80 (grade A or A+).

> **Note on IV sanity (single-leg):** IVR > 70 does not reject the candidate — it scores 0 on
> this component and the rubric routes the structure to a debit spread (per Phase 2 Engine B
> IV-aware routing). The candidate can still reach A+ grade if the other components are strong.

## Phase 4: Sizing

This section defers all sizing-framework decisions to `OPERATING_MANUAL.md §3`. Options math maps
onto the Manual by substituting `max_loss_per_unit` for `(entry − stop)`. Every value here is
derived from or stricter than §3–4 of the Manual — nothing is looser.

### Step 1 — Sizing formula

Equity (`E`) is always **live equity read from `get_account` at order time** — never cached, never
approximated. This keeps sizing tied to the true capital base and ensures compounding is structural.

```
risk_dollars      = E * risk_pct                       # E = live equity from get_account

max_loss_per_unit = (spread_width - credit) * 100      # credit spreads
                  = debit_paid * 100                   # debit spreads / single-leg

contracts         = floor(risk_dollars / max_loss_per_unit)   # must be >= 1, else SKIP
```

If `contracts < 1` after the floor: **SKIP the trade.** Do not enter with fractional conviction
or round up — a position too small to size at 1 contract means the account is below the practical
minimum for this structure at this conviction level. Log the skip with `rules_triggered: ["SIZE_TOO_SMALL"]`.

### Step 2 — Conviction-scaled `risk_pct`

Per-trade risk is conviction-scaled with **no fixed ceiling on A+ trades.** The justification:
options max-loss is hard-capped by the spread width or premium paid — unlike an equity stop, which
can gap through. Because the loss cannot exceed `max_loss_per_unit * contracts` regardless of how
the underlying moves, scaling up on an A+ setup does not expose the account to a runaway loss.
This logic does **not** apply to equity stops; it is specific to defined-risk options structures.

The conviction `risk_pct` values below **supersede** `config.yaml`'s default `max_risk_per_trade_pct`
(`R_pct`, default 1.0%) for options positions under this SOP. `R_pct` remains the per-trade ceiling
for equity SOPs; for defined-risk options, this table is the governing per-trade risk.

| Score | Grade | Per-trade risk (defined max-loss) |
|---|---|---|
| 70–79 | B+ | ~1.5% |
| 80–89 | A | ~3% |
| 90–100 | A+ | up to the full heat headroom (no fixed cap) |

Anything scoring **< 70** (Reject grade) is **not sized** — skip without entry. This is the same
reject threshold as Phase 3 Scoring; sizing never overrides a scoring rejection.

> **A+ headroom in practice:** "up to the full heat headroom" means `risk_pct` for a given A+
> trade is whatever remains between the current portfolio heat and the 6% heat cap (see Step 3).
> If existing open positions already consume 4% heat, the maximum available for a new A+ trade is
> 2% — the cap is always the binding constraint.

### Step 3 — Account-level backstops (HELD — non-negotiable)

These backstops are the capital-preservation floor. They are **never loosened by this SOP** and
take precedence over conviction-scaled sizing. Compute them against live equity from `get_account`
before placing any order.

**Portfolio heat cap — 6%**

The sum of `max_loss_per_unit * contracts` across **all open positions** must not exceed 6% of
equity. Before placing a new order, compute the prospective new heat:

```
current_heat_pct = sum(max_loss_per_unit * contracts for each open position) / E * 100
new_heat_pct     = current_heat_pct + (max_loss_per_unit * contracts_proposed) / E * 100

if new_heat_pct > 6.0: reduce contracts_proposed, or SKIP if contracts < 1 after reduction
```

**Single-leg sub-leash — 3%**

Total open max-loss across **single-leg positions only** must not exceed 3% of equity. Single-leg
longs are lower-win-rate, theta-bleeding bets; they must not crowd out Engine A's steady income
stream. Apply the same prospective-heat check as above, restricted to the single-leg sub-bucket:

```
single_leg_heat_pct = sum(debit_paid * 100 * contracts for each open single-leg position) / E * 100

if single_leg_heat_pct + new_single_leg_heat > 3.0: reduce or SKIP
```

**Manual circuit breakers — stand, unchanged (`OPERATING_MANUAL.md §4`)**

The following circuit breakers from the Manual apply without modification:

| Trigger | Action |
|---|---|
| Realized P&L ≤ −3% of equity in one day (`DLL_pct`) | HALTED — close all, activate kill switch (`§4.3`) |
| Drawdown from peak equity ≥ −6% in 5 trading days | HALTED for the week — operator must clear (`§4.4`) |
| Drawdown from peak equity ≥ −10% in any rolling 20 days | HALTED indefinitely — no autonomous restart (`§4.4`) |

**Kelly cap — `OPERATING_MANUAL.md §3.4` still applies**

Even when conviction is A+ and heat headroom exists, `risk_pct` must not exceed `size_cap_pct`
as computed by the Kelly formula in Manual §3.4:

```
kelly_pct     = win_rate - (loss_rate / (avg_win$ / avg_loss$))
size_cap_pct  = max(0, min(risk_pct, 0.25 * kelly_pct))
```

Use `size_cap_pct` as the effective `risk_pct` when it is smaller than the conviction-scaled
target. This guards against a winning streak inflating size just before mean reversion.

### Natural governor

Any single trade sized past **~3% max-loss** will, if it loses, alone consume the full daily halt
threshold (`DLL_pct = −3%`). This means an oversized A+ bet is self-limiting at the account level:
the daily circuit breaker fires before a second loss can compound the damage. Conviction can swing
large on a genuine A+ setup; the account cannot be bled to death by one bad call.

## Phase 5: Entry Gates & Order Placement

Entry is the last checkpoint before capital is committed. All gates below are evaluated **after**
Phase 3 scoring has produced a grade (B+ or better) and Phase 4 sizing has produced a valid
contract count (≥ 1). Passing every hard gate is a prerequisite; soft-gate failures adjust size
but do not cancel the trade.

### Hard Gates — any failure → skip today

All eight conditions must be true. A single failure means do not enter; log with
`action="gate_fail"` and the specific rule ID.

| Gate | Condition | Rule ID |
|---|---|---|
| **SPY regime agrees with direction** | SPY regime (Phase 1) aligns with the trade direction — UPTREND for bullish structures, DOWNTREND for bearish structures, per Phase 1 equity regime gate. | `HARD_SPY_REGIME` |
| **Stock regime agrees with structure** | The stock's own EMA20/SMA50 structure aligns with the trade direction (no structure against the grain). | `HARD_STOCK_REGIME` |
| **IVR zone or continuation setup** | Engine A: IVR is in the correct zone (> 75 for credit, < 25 for debit). Engine B: one of the three accepted continuation setups (Phase 2) is confirmed. A candidate must satisfy the criterion for the engine it is entering under — the two criteria are not interchangeable. | `HARD_IVR_ZONE` (Engine A) / `HARD_CONTINUATION` (Engine B) |
| **No earnings inside expiry window** | Confirmed earnings date falls entirely outside the expiry window, OR the expiry window starts > 7 calendar days after earnings. If earnings date is unavailable or uncertain: skip. | `HARD_EARNINGS_CLEAR` |
| **Current time ≥ 9:45 ET** | Do not enter in the first 15 minutes of the session — spreads are wide, fills are erratic. | `HARD_TIME_GATE` |
| **Spread bid-ask ≤ 20% of mid** | For multi-leg spreads: the net spread bid-ask must be ≤ 20% of the net mid. For single-leg: the option bid-ask ≤ 20% of mid. | `HARD_SPREAD_WIDTH` |
| **Portfolio heat after this trade ≤ 6%** | `new_heat_pct` (Phase 4 Step 3) must not exceed 6% of live equity. | `HARD_HEAT_CAP` |
| **Single-leg heat after this trade ≤ 3%** | For single-leg entries only: `single_leg_heat_pct` after the proposed trade must not exceed 3% of live equity. | `HARD_SINGLELEG_LEASH` |

### Soft Gates — failure → reduce size, not skip

Soft-gate failures do not cancel the trade. They trigger a one-step-down conviction reduction:
A+ → A risk_pct; A → B+ risk_pct; B+ → pass but note concern. Log with `action="gate_fail"`
and `rules_triggered` listing the soft rule ID alongside the size reduction.

| Gate | Condition | Rule ID |
|---|---|---|
| **IV/HV confirms vol direction** | Engine A credit: IV/HV > 1.1. Engine A debit: IV/HV < 0.85. Engine B: no threshold (not a vol-edge play). | `SOFT_IVHV_CONFIRM` |
| **Put-skew confirms** | For bull put spreads: put_skew > 0 (tail risk slightly elevated on put side, confirming the credit makes sense). Negative put_skew is a warning. | `SOFT_PUTSKEW` |
| **Option volume ≥ 100 on target strike** | Today's traded volume on the specific target strike (not just open interest) is ≥ 100 contracts. Below 100 is thin; fills may slip. | `SOFT_OPTION_VOLUME` |
| **Social signal neutral or confirming** | No active negative social / news signal against the trade direction. A neutral reading is fine; a strong contrary social signal warrants a size step-down. | `SOFT_SOCIAL` |

### Order Placement

**Multi-leg spreads (bull put, bear call, debit vertical, momentum debit spread):**

- Place as a **single limit order at the net mid price** — never leg in separately unless the broker
  requires it, and never use market orders on spreads (the bid-ask gap makes market fills
  unacceptable).
- **Credit spreads:** start $0.05–0.10 better than the net mid (i.e., try to collect slightly more
  than mid). If unfilled after 5 minutes, relax to mid. Do not go below mid on credit spreads.
- **Debit spreads:** start at mid. If unfilled after 5 minutes, relax to $0.05–0.10 above mid.
  Do not chase beyond $0.10 over mid — if still unfilled, cancel and reassess liquidity.
- If a multi-leg limit order is partially filled: cancel the remaining legs immediately. Do not
  hold an unbalanced leg of a spread position; it converts defined-risk into undefined-risk.

**Single-leg longs (call or put):**

- Place a **limit order at or near the mid**. Adjust by one tick if the market is moving; do not
  chase by more than $0.05 above ask.
- If unfilled after 10 minutes: cancel and reassess whether the thesis still holds.

**On fill:**

Log the fill immediately via `log_decision(action="enter", ...)` with: fill price, contracts,
max_loss_per_unit, heat consumed, and the exit-reason enum reserved field set to `null`.

## Phase 6: Exit Framework

The exit loop runs **daily at 15:30 ET** as a cross-day check. This SOP holds positions overnight
and across sessions — the 15:30 check is not a flatten; it is a structured review that may or may
not result in a close. No mechanical end-of-day flatten is applied to open options positions under
this SOP. The loop evaluates open positions in **most-urgent-first order**: emergencies are acted
on before end of day; trailing and thesis checks may result in next-open orders if time has expired.

### Most-Urgent-First Ordering

1. Emergency exits (act same-day — see below)
2. Always-on mechanical rules
3. Trailing profit-protection stops
4. Thesis integrity checks
5. Single-leg specific rules
6. Roll evaluation (only if position is clean)

---

### Always-On (Mechanical — no LLM judgment required)

These rules fire automatically based on position data. They require no qualitative assessment.

| Rule | Condition | Action | Exit reason |
|---|---|---|---|
| **50% max-profit close** | Credit spread current value ≤ 50% of credit collected (i.e., buyback costs half the original credit or less) | Close the spread | `50pct_profit` |
| **21-DTE hard close** | Credit spread with DTE ≤ 21 | Close the spread (gamma-acceleration zone; theta gains no longer justify the pin risk) | `21dte_hard_close` |
| **2× loss limit** | Credit spread: current value ≥ 2× credit collected. Debit spread or single-leg: current value ≤ −2× debit paid (i.e., value has fallen to debit_paid − 2×debit_paid = effectively worthless relative to a doubled loss). More precisely: debit/single-leg close when the unrealized loss exceeds 2× debit paid. | Close the position | `2x_loss_limit` |
| **No expiration holding** | Any open position with DTE = 1 (one trading day remaining before expiry) | Close at ≥ 1 day before expiry — do not hold through expiration. Log with exit reason. | `21dte_hard_close` (or `manual_early_close` if operator-directed) |

---

### Trailing (Profit Protection)

Trailing rules activate once a position has moved into profit. They lock in gains before they
evaporate. The LLM confirms the trigger; execution is mechanical.

**Credit spreads — value stop:**

Track the lowest spread value (best mark) seen since entry. If the current spread value has risen
more than 20% above that best mark (i.e., the position has given back > 20% of the best-gain
level), close the spread.

```
best_mark       = min(spread_value_since_entry)      # lowest value = best for credit spread seller
current_value   = spread mark-to-market now
given_back_pct  = (current_value - best_mark) / best_mark * 100

if given_back_pct > 20: close → trailing_stop
```

**Scale at +100%:** If the credit spread's value has fallen to ≤ 25% of credit collected (= 75%
profit on the spread), consider scaling out 50% of the position to lock gains while letting the
remaining 50% run to the 50%-profit close trigger.

**Debit spreads and single-leg longs — value stop:**

Track the highest value (best mark) seen since entry. Close if current value falls below 75% of
that peak.

```
best_mark       = max(value_since_entry)
current_value   = value mark-to-market now
retained_pct    = current_value / best_mark * 100

if retained_pct < 75: close → trailing_stop
```

**Scale at +100%:** If the debit spread or single-leg has doubled in value (current value ≥ 2×
debit paid), sell 50% of the position. Reset the trailing stop on the remaining 50% from the
+100% level.

Exit reason for all trailing closes: `trailing_stop`.

---

### Thesis Integrity

These checks assess whether the original trade thesis still holds. The LLM reads the current
regime and vol data and makes a qualitative judgment. Run at 15:30 ET.

**Regime check — EMA20 / SMA50:**

Evaluate the stock's current EMA20 and SMA50 relationship against the trade direction.

- **INTACT:** Price and moving averages still aligned with the original thesis direction.
- **WEAKENING:** One of EMA20 or SMA50 has crossed but the other has not; or price has
  crossed EMA20 but not SMA50.
- **BROKEN:** Both EMA20 and SMA50 have crossed against the trade direction, or price is now
  clearly on the wrong side of both.

**Vol-thesis check:**

Evaluate whether the original vol rationale still applies (Engine A: IVR still supports the
structure; Engine B: momentum still present).

- **INTACT:** IVR / IV-HV still in the zone that motivated the structure.
- **BROKEN:** IVR has reverted to the neutral zone (25–75) from a credit-spread entry, OR
  IVR has expanded above 50 from a single-leg long entry.

**Short-strike safety (credit spreads):**

Evaluate the short strike's current delta and distance from the underlying price.

| Status | Condition |
|---|---|
| **SAFE** | Distance > 8% from current price AND short-strike delta < 0.25 |
| **CAUTION** | Distance 4–8% OR delta 0.25–0.35 |
| **THREATENED** | Distance < 4% OR delta > 0.35 |

**Actions:**

| State | Action | Exit reason |
|---|---|---|
| Regime BROKEN | Close the full position | `thesis_broken_regime` |
| Vol BROKEN | Close the full position | `thesis_broken_vol` |
| THREATENED + regime WEAKENING | Reduce position by 50% (close half the contracts) | `strike_threatened_size_reduce` |
| CAUTION only | No action; note in log; re-evaluate at next 15:30 check | — |
| SAFE / INTACT | No action | — |

---

### Single-Leg Specific

**IV-crush rule:**

After an earnings event, catalyst, or major vol-compressing event:

- **Moved AND IV crushed:** The underlying moved in the expected direction AND implied volatility
  has compressed significantly (IV/HV now < 0.85). → **Take profit.** The option will not re-rate
  higher; the vol is gone and the move is captured. Exit reason: `50pct_profit` if at a profitable
  close, otherwise `trailing_stop`.
- **No move AND IV crushed:** The underlying did NOT move (or moved against) AND implied volatility
  has crushed. → **Cut the position.** The thesis has failed — there is no remaining catalyst to
  rerate the option. Exit reason: `iv_crush_no_move`.

**Time stop:**

If a single-leg position is not profitable (current value < debit paid) by mid-DTE (i.e., half
the original DTE has elapsed), close the position. A single-leg that has not begun working by the
midpoint of its life is unlikely to recover to breakeven with remaining theta working against it.

Exit reason: `2x_loss_limit` if the position is at a loss; `manual_early_close` if still near
breakeven but time-stopped by the mid-DTE rule.

### Emergency (Act Same-Day)

Emergency exits override the normal 15:30 workflow. When an emergency trigger is detected at
any time during the session, the Monitor agent acts before the close of that day — not at the
next 15:30 check.

**Execution rule for all emergencies:** use a **limit order at or near mid**. Never use a market
order on spreads, even in an emergency. Place limit $0.05–0.10 wide of mid; if unfilled after
2 minutes, widen to the current bid (for closing a long leg) or ask (for closing a short leg).

| Trigger | Action | Exit reason |
|---|---|---|
| **Gap through strike** | The underlying gaps through (opens beyond) the short strike of a credit spread, or gaps through the long strike of a protective spread. | Immediate defensive exit (limit at/near mid, acting before end of day) | `gap_through_strike` |
| **SPY regime collapse** | Per `OPERATING_MANUAL.md §4.4`: drawdown from peak equity ≥ 10% in any rolling 20 days, or the SPY itself has violated the regime structure that gated the original entry (EMA20 crosses below SMA50 in UPTREND, or vice versa in DOWNTREND) with accelerating slope. The Manual's catastrophic stop provisions apply (`§4.4`). | Immediate defensive exit on all options positions; activate kill switch if Manual triggers apply | `market_regime_collapse` |
| **Binary event inside window** | An unscheduled or newly-confirmed earnings date, FDA decision, merger announcement, or other binary event is now confirmed to land inside the expiry window, and it was not present at entry. | Immediate defensive exit (limit at/near mid, acting before end of day) | `binary_event_in_window` |

### Roll Logic

Rolling (closing the current position and opening a replacement with a different expiry or strike)
is permitted only under all of the following conditions:

1. The current position is **untested** (short strike not approached) OR **profitable** (current
   P&L > 0).
2. The **vol edge is still intact** at entry conditions for the new position (IVR still in the
   correct zone for Engine A; continuation setup still present for Engine B).
3. The new position would pass **all Phase 5 hard gates** as if it were a fresh entry.
4. Rolling does **not** increase the total max-loss vs. the current position.

**Never roll a breached position** (short strike tested or crossed, or position at a loss) to
avoid recognizing a loss. Rolling a losing position forward is loss-deferral, not risk management.
If the position is breached: take the loss and close cleanly.

Exit reason for the closing leg of a roll: `roll_replaced`.

## Phase 7: Cost Tracking & Journal

### Cost Tracking

The EOD Review agent reports the following daily cost summary alongside realized P&L:

| Item | Source |
|---|---|
| **LLM token burn** | Token counts from today's agent invocations, converted to estimated cost at current model pricing |
| **Broker/regulatory fees** | Per-contract regulatory fees (Alpaca is commission-free; OCC/SEC/FINRA per-contract fees still apply) and any platform fees |
| **Total daily cost** | Token burn + broker fees |
| **Realized P&L net of costs** | Realized P&L − total daily cost |

**The cost gate is OFF.** `config.yaml` key `income.target_per_day_usd` is set to `0`. This means
costs are tracked and reported in EOD review, but the system never blocks or defers a trade because
costs have not yet been covered by P&L. This is a reporting-only metric. It must never be
reconfigured to block trading without a SOP version bump and operator approval.

### Journal Schema

Every trade decision is logged via `log_decision(...)`. The base required fields are defined in
`OPERATING_MANUAL.md §6`. This SOP adds the following options-specific fields on top of the base:

**`OPERATING_MANUAL.md §6` base fields (required on every log):**

| Field | Required content |
|---|---|
| `agent` | One of: `orchestrator`, `research`, `trader`, `monitor` |
| `action` | One of: `enter`, `exit`, `skip`, `adjust`, `halt`, `preflight_complete`, `gate_pass`, `gate_fail` |
| `rules_triggered` | List of rule IDs from this SOP |
| `reasoning` | One-sentence thesis or rejection reason |
| `market_context` | Snapshot of price, regime, vol — enough to replay the decision |
| `sop_version` | `options-vol-edge/v1.0.0` |

**Options-specific fields (required on enter / exit / adjust for options positions):**

| Field | Type | Description |
|---|---|---|
| `iv_rank` | float (0–100) | IVR at the time of the decision |
| `iv_hv` | float | IV30 / HV20 ratio at the time of the decision |
| `delta` | float | Delta of the short strike (credit spreads) or long leg (debit / single-leg) at the time of the decision |
| `theta` | float | Net daily theta of the position |
| `vega` | float | Net vega of the position |
| `structure` | string | One of: `bull_put_spread`, `bear_call_spread`, `debit_vertical_call`, `debit_vertical_put`, `momentum_debit_spread_call`, `momentum_debit_spread_put`, `single_leg_call`, `single_leg_put` |
| `engine` | string | `A` or `B` |
| `max_profit` | float | Maximum achievable profit in dollars (credit × 100 × contracts for credit spreads; (width − debit) × 100 × contracts for debit spreads; uncapped for single-leg) |
| `max_loss` | float | Maximum possible loss in dollars (max_loss_per_unit × contracts) |
| `breakeven` | float | Underlying price at which the position breaks even at expiry |
| `dte` | int | Days to expiration at the time of the decision |

**On exits:** additionally include `exit_reason` set to exactly one value from the exit-reason enum
(Phase 6, verbatim list). The `rules_triggered` list must also include the same exit-reason value.
