# Equity Swing SOP — v1.0.0 (Two-Engine: Momentum + Mean-Reversion)

**Status:** initial version, thresholds `BOOK-DERIVED` (adapted from Bensdorp,
*Automated Stock Trading Systems*, 2020 — Systems 1, 3, 5) pending backtest
calibration. Governed by `OPERATING_MANUAL.md`. Changes require a new version
file — never edit in place.

**Design principle (Bensdorp's 12 ingredients):** every trade must have ALL of:
objective, belief, universe, filters, setup, ranking, entry, stop-loss, reentry,
profit protection, profit taking, position sizing. A candidate missing any
ingredient is NOT a trade.

**Why two engines:** momentum-long and dip-buying are non-correlated return
streams — momentum pays in trending tape, mean-reversion pays in choppy/pullback
tape (book ch. 2, 7). Running both smooths the weekly P&L; the routing SOP
decides which engine(s) the current regime allows.

---

## Engine M — Momentum Continuation (book System 1, adapted to swing horizon)

**Objective:** ride established leaders for 5–20 sessions during favorable tape.
**Belief:** stocks in strong uptrends with relative strength persist; the edge
comes from staying in winners, not from picking bottoms. Expect win rate near
45–50% with avg-win ≥ 2× avg-loss (book Sys-1 profile: 45% WR, 3.2 W/L).

### Gatekeeper (ALL must pass — hard gates, no agent override)

| # | Gate | Rule | Source |
|---|------|------|--------|
| M-G1 | Regime | `equity/swing` engine M eligible per `sops/_routing/` §1 (SPY above SMA50, trend up) | Sys-1 SPY>SMA100 gate, adapted to available signals |
| M-G2 | Liquidity | 20-day avg dollar volume ≥ $50M; price $10–$500 | Sys-1 filter |
| M-G3 | Volatility band | ATR10 between 1.5% and 6% of price | book: volatility is required, but cap for sizing sanity |
| M-G4 | Trend alignment | SMA25 > SMA50 AND close > SMA25 | Sys-1 setup |
| M-G5 | Relative strength | 10-day return ≥ SPY + 2% | existing scanner Filter 2 |
| M-G6 | Momentum | 50-day ROC ≥ +10% | Sys-1 ranking input (200d ROC, shortened for swing horizon) |
| M-G7 | Anti-chase | close ≤ SMA25 + 2.5×ATR10 AND NOT (within 2% of 10d high AND +5% in 5d) | book ch.6 "stops outside noise"; existing chase filter |
| M-G8 | Earnings | no confirmed earnings within next 5 sessions. Unknown → proceed at half conviction | binary-event risk |
| M-G9 | Portfolio | open heat + new risk ≤ 6% equity; positions < max (config) | OPERATING_MANUAL §3 |

### Ranking
More setups than slots → rank by **highest 50-day ROC** (book Sys-1: join the
strongest crowd). Tiebreak: higher ATR%.

### Entry
- Next-session **market-on-open** (book Sys-1: guaranteed entry, slippage acceptable
  for multi-day holds).
- **Gap rules (NON-NEGOTIABLE, CLAUDE.md):** gap up > 5% above prior close → SKIP
  (chasing); gap down > 3% → SKIP (thesis broken).

### Stop-Loss
2.5 × ATR10 below fill price (book uses 5×ATR20 for 200-day holds; halved for the
5–20 session horizon — still "outside the noise").

### Reentry
Stopped out, setup re-qualifies later? **Take it** (book ch.6 §9: yesterday has
no bearing on today). Max 2 entries per symbol per week.

### Profit Protection
- ≥ +1R: move stop to breakeven.
- ≥ +1.5R: trail 2 × ATR10 below highest close. Trail only moves up.
(Adapted from Sys-1's 25% trail; matches Monitor agent mechanics.)

### Profit Taking
None — let winners run (book Sys-1). **Time stop: 20 sessions** → exit next open.

### Position Sizing
Risk per trade = 1% equity (config `max_risk_per_trade_pct`), capped by quarter-Kelly
(OPERATING_MANUAL §3.4). Max position = 10% equity notional (book: 2%/10% rule).
`shares = floor(risk_$ / (fill − stop))`.

## Engine R — Mean-Reversion Dip (book Systems 3 + 5 hybrid)

**Objective:** buy sharp, statistically stretched selloffs in long-term uptrends;
exit within days. **Belief:** a liquid stock in an uptrend that drops hard in 3
days reverts to its mean more often than random; the edge is paid for by buying
when it feels worst (book: "buying a falling knife... experienced traders want in").
Expect the HIGHER win rate engine: book Sys-3 ≈ 63% WR, short holds, small wins.

### Gatekeeper (ALL must pass)

| # | Gate | Rule | Source |
|---|------|------|--------|
| R-G1 | Regime | engine R eligible per `sops/_routing/` §1 — note R stays ON in mild corrections (that's where it earns) | book ch.7 non-correlation |
| R-G2 | Liquidity | 20-day avg dollar volume ≥ $50M; price ≥ $10 | Sys-3 filter (1M sh / $1 min, raised for our universe) |
| R-G3 | Volatility | ATR10 ≥ 2.5% of price | Sys-3 requires 5% on all-stocks; our mega-cap universe is calmer — `BOOK-DERIVED`, calibrate |
| R-G4 | Long uptrend intact | close > SMA150 | Sys-3 setup |
| R-G5 | Stretch | 3-day drop ≥ 6% AND RSI3 < 30 | Sys-3 (12.5% on 5%-ATR stocks, scaled ≈ half for half the ATR) + Sys-5 RSI pullback |
| R-G6 | Earnings | no earnings before expected exit (4 sessions). Unknown → half conviction | binary risk inside a knife-catch |
| R-G7 | Thesis-break veto (AI) | the drop must NOT be caused by a structural break: fraud, guidance cut, regulatory action, secular demand loss. Sector sympathy, index selloff, analyst noise, profit-taking = tradeable. **This veto is the AI's edge over pure code** — Bensdorp trades these blind; we don't have to | hybrid architecture (CLAUDE.md) |
| R-G8 | Portfolio | heat + new risk ≤ 6%; positions < max | OPERATING_MANUAL §3 |

### Ranking
**Biggest 3-day drop first** (book Sys-3). Tiebreak: lower RSI3.

### Entry
- **Limit order 3% below previous close**, day-only (book Sys-5; Sys-3's 7% is for
  wilder stocks). No fill → no trade; expect only a fraction of orders to fill
  (book: "you might place ten orders and only execute three or four").
- Backtest fill rule: open < limit → fill at open; else day low ≤ limit → fill at
  limit; else no fill.

### Stop-Loss
2.5 × ATR10 below fill (Sys-3). Wide on purpose — the stock needs room to bottom.

### Reentry
Allowed if setup re-qualifies (book ch.6 §9). Max 2 per symbol per week.

### Profit Protection
**None** (book: MR trades are too short for trailing stops).

### Profit Taking
- Close ≥ +4% above fill → exit next session market-on-open (Sys-3 target, Sys-5 exit style).
- **Time stop: 4 sessions** without target or stop → exit next open (Sys-3: 3d, Sys-5: 6d; midpoint).

### Position Sizing
Same as Engine M: 1% risk, quarter-Kelly cap, 10% notional cap.

## Shared Rules

1. **Engines are independent budgets** but share the 6% portfolio heat cap and
   the position-count cap from config.
2. **One engine per symbol** — never hold M and R positions in the same name.
3. The trade plan MUST record `engine: M | R` — the Monitor agent applies
   engine-specific exits from this field.
4. Decision logging per OPERATING_MANUAL §6 with `rules_triggered` naming the
   gates that passed/failed (e.g. `["M-G4", "M-G7-FAIL"]`).
5. Win-rate expectations differ BY DESIGN: M ≈ 45–50% with big winners,
   R ≈ 55–65% with small winners. Judge each engine by **expectancy per R**,
   not blended win rate (Tharp; book ch.4).
