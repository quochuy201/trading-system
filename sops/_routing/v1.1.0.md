# Strategy Routing SOP — v1.1.0

**Status:** human-ratified. Versioned like any SOP — propose changes via
`reports/sop-changes/`, never edit in place. The agent APPLIES this; it never
edits it. Governed by OPERATING_MANUAL.md (constitution) and
docs/AGENT_EVOLUTION_STANDARD.md (risk-bearing skill-routing).

Inputs come from `get_market_regime`. A `null` signal in any condition →
treat the dependent strategy as **OFF** (fail-safe). On rule conflict,
**most-restrictive wins**. The gate can only SUBTRACT from what mode/limits
already allow — never add.

## §1 Eligibility Gate (Risk-Manager applies, in preflight)

Evaluate top-to-bottom; **first matching row wins**. Cell values:
`ON` (all engines) · `OFF` · `R-ONLY` (equity/swing mean-reversion engine only)
· `M-ONLY` (equity/swing momentum engine only).

Equity rows intentionally use **price-derived signals only** (no iv_rank) so
they remain computable in backtest, where iv_rank_spy is null by design;
iv_rank gates only the options column.

| Regime condition | equity/intraday | equity/swing | options/vol-edge |
|---|---|---|---|
| vix > 30 OR spy_tr_atr > 2.0 (stress) `[PLACEHOLDER-FAIL-SAFE]` | OFF | OFF | OFF |
| iv_rank_spy > 70 AND abs(spy_vs_sma50_pct) < 2 (high-vol range) `[PLACEHOLDER-FAIL-SAFE]` | OFF | R-ONLY | ON |
| spy_vs_sma50_pct > 0 AND spy_trend = up (uptrend) `[BOOK-DERIVED]` | ON | ON | OFF |
| spy_vs_sma50_pct > -5 AND spy_trend in {flat, down} (mild correction / chop) `[BOOK-DERIVED]` | OFF | R-ONLY | OFF |
| default (no row matched) | OFF | OFF | OFF |

Rationale for the new row (v1.1.0): mean-reversion dip-buying (swing Engine R,
Bensdorp Systems 3/5) earns precisely in pullback/chop weeks while momentum
engines sit out — running non-correlated engines smooths weekly P&L (book
ch. 2, 7). The stress row above still turns everything OFF.

Only strategies that are (a) in `config.yaml strategies.enabled`, (b) match the
session `--market` scope, AND (c) ON above are eligible.

## §2 Setup Routing (Research applies, per candidate, eligible strategies only)

| Candidate signature | → strategy |
|---|---|
| premarket gap > 3% AND RVOL > 2x AND fresh catalyst (<=48h) | equity/intraday-momentum |
| SMA25 > SMA50 AND close > SMA25 AND RS10 ≥ SPY+2% AND ROC50 ≥ +10% (momentum continuation) | equity/swing — engine M |
| 3-day drop ≥ 6% AND RSI3 < 30 AND close > SMA150 (mean-reversion dip) | equity/swing — engine R |
| iv_rank > 70, range-bound, liquid options chain | options/vol-edge |
| (no clear match) | DROP — log "unroutable" |

A candidate routed to a strategy/engine that is not eligible (per §1) is dropped
with log reason "ineligible: <regime reason>".
